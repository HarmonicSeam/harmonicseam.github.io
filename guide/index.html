使い方

Windows 版（2026年10月）の手順。HarmonicSeam を開いたところから。

  1. ① 見本で鳴らす入っている3曲で、切り替えと橋を聴く。10分。
  2. ② 自分の曲で自分の MIDI で、切り替えと橋を聴く。30分。
  3. ③ 書き出すゲームや DAW に渡す物（橋の音声・MIDI、ゲーム用のデータ）を作る。
  4. ④ Unity で鳴らす書き出した物を Unity で鳴らす。Unity を使う人だけ。

① 見本で鳴らす

  1. ［ファイル］→［開く…］で 見本\レクイエムとK545\レクイエムとK545.hsproj を開く。
  2. 左の［継ぎ目］を1本選ぶ。上の帯が切替点。
    緑＝切れる黄＝橋なら切れる灰＝そのままでは切れない
    斜線＝禁則は無いが、曲Aが解決しないまま曲Bに入る所（橋なしでは切らない）
  3. 帯をクリックして、［試聴］の ▶ で聴く。
  4. 左の［ライブ］で曲の名前を押すと鳴る。鳴っている間に別の曲を押すと、次に切れる所で移る。

② 自分の曲で

曲ごとに MIDI を1つ（全トラック入り）。曲はループとして扱う。テンポと拍子は途中で変えない。

  1. ［ファイル］→［新規］。
  2. 曲ごとに［MIDI］の［…］で選ぶ。3曲目からは左の［曲］の［＋］。
  3. 左の［継ぎ目］を選び、①と同じく聴く。ほかの組は［＋］で足し、右の［つなぐ］で2曲を選ぶ。
  4. 橋は右の［橋］で替えられる（レシピ・長さ・音型）。
  5. ［ファイル］→［保存］。MIDI と同じドライブに保存する（違うと、開き直したときに曲が見つからないことがある）。

読み違えたとき

  • 調が違う → ［調］で固定。途中で変わるなら［＋ 調が変わる小節］
  • 拍子が違う → ［拍子を固定］
  • ドラムなどが混ざる → ［▸ トラック］で外す
  • 1つの MIDI に何曲もある → ［▸ 範囲］で選ぶ

音声を付けるとき

  • ［音源］の［…］で WAV か mp3 を選ぶと、曲がその音で鳴る。
  • MIDI と同じ所から、1周ぶんちょうどで書き出しておく。頭の空白も、ループのたびに鳴る。
  • 頭が MIDI より遅れているときは、［測定］でカウントインが入る。

楽器

  • まずは内蔵の音色で。VST3 は左の［楽器］から読める。
  • フォルダの形の .vst3 は、中の Contents\x86_64-win\ にある .vst3 を選ぶ。

③ 書き出す

左の［書き出し］で出す物に印を付け、［書き出し］でフォルダを選ぶ。

継ぎ目の札・マーカー・JSON
札（.txt）：切替点と判定／マーカー（.mid）：DAW で切替点に印／JSON：Unity 用
橋の MIDI
橋の音符。DAW で好きな音色に
橋の仕様
和音進行と、検査した項目（.txt）
橋の音声
橋の WAV（［楽器］の音で）

④ Unity で鳴らす

Unity 6000.3 以降。受け取った zip の中の HarmonicSeam-Unity.tgz を使う。

  1. Package Manager の［＋］→［Install package from tarball…］で .tgz を選ぶ。署名なしの知らせは気にしなくてよい。
  2. （Windows 版で）曲に音声を付けて、［継ぎ目の札・マーカー・JSON］と［橋の音声］を書き出す。
  3. 曲の音声と橋の WAV を Assets に入れる。
  4. ［Create］→［HarmonicSeam］→［MusicTrackData］。
  5. JSON を Assets に入れ、［取り込む］。
  6. Samples から Demo Songs を Import。空の GameObject に SampleSwitcher を付け、［曲のデータ］に手順4で作った MusicTrackData を入れて Play。左下のボタンで最初の2曲を切り替える。

自分のゲームでは、自分のスクリプトから SwitchTo を呼んで切り替える。切り替えの予定・完了・取り消し・断りは、知らせとして受け取れる。

分からないときは連絡先へ。
